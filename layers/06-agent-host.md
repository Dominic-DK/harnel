# 6. 에이전트 호스트

에이전트가 실행되는 컨테이너입니다. 인터넷 접근 권한과 계정 키가 없으며, 마운트된 폴더 밖에는 쓸 수 없습니다. 컨테이너 1개가 권한 경계 1개입니다. 에이전트 1개는 프로필 1개입니다. 프로필은 해당 에이전트의 정책을 정의하는 파일입니다.

## 원칙

- **모델은 제안만 합니다.** 동작의 허용 여부는 각 도구 함수 안의 코드가 결정합니다. 모델이 스스로 자제하는 것은 통제 수단으로 간주하지 않습니다.
- **기본 거부.** 정책에 명시된 파일 확장자, 기능, 호출자만 허용됩니다.
- **승인은 실행 1회에만 유효합니다.** 내용, 대상, 요청자, 정책 중 하나라도 바뀌면 새 승인이 필요합니다.
- **같은 쓰기는 한 번만 적용됩니다.** 승인이 두 번 도착하면 영수증을 먼저 기록한 실행만 쓰기를 수행합니다.
- **제한은 에이전트 외부에 둡니다.** 프롬프트가 아니라 마운트, 네트워크, 게이트웨이가 제한을 강제합니다.
- **검증은 집행과 다른 방법으로 합니다.** 판정을 반복하지 않고, 실제로 생성된 출력을 검사합니다.

## 책임

요청은 다음 검사 지점을 순서대로 통과합니다.

| 순서 | 검사 지점 | 검사 내용 |
| --- | --- | --- |
| 1 | 호스트 입구 | 위임 토큰의 서명과 만료 |
| 2 | 입력 형식 | 알 수 없는 필드가 있는 요청은 거부 |
| 3 | 인가 | 토큰의 주체가 이 기능을 사용할 수 있는지, 입력 크기, 호출 빈도 |
| 4 | 실행 전 스냅샷 | 쓰기 가능한 폴더의 상태를 저장 |
| 5 | 도구 실행과 검사 | 경로 판정, 차단 목록, 결과에 숨긴 경로나 비밀 내용이 포함됐는지 |
| 6 | 모델 호출 | 모델 게이트웨이로만 전송 |
| 7 | 출력 마스킹 | 토큰이나 비밀번호 형태의 값을 마스킹 |
| 8 | 결과 대조 | 예상한 변경만 발생했는지, 응답에 비밀 내용이 포함됐는지 |
| 9 | 전송 전 검사 | 응답이 호스트를 떠나기 전의 최종 검사 |

## 책임 범위 밖

- 인터넷 직접 접근. 접근 가능한 대상은 모델 게이트웨이뿐입니다.
- 모델 계정 키 보유.
- 다른 호스트 호출.

## 프로필 내용

| 필드 | 설명 |
| --- | --- |
| 읽기 경로 | 컨테이너에 마운트된 폴더 안의 범위 |
| 쓰기 경로 | 없음, 또는 별도로 마운트된 폴더 |
| 차단 목록 | 환경 파일, 키, 인증서, 운영 데이터베이스. 어떤 승인으로도 열 수 없습니다. |
| 읽기 허용 목록 | 파일 확장자와 이름. 로그처럼 목록에 없는 파일은 승인을 받아 해당 요청에 한해 엽니다. |
| 허용 주체와 기능 | 어떤 사용자 또는 서비스 신원이 무엇을 할 수 있는지 |
| 승인자 | 트리거로 시작된 작업의 쓰기를 승인하는 사용자 |
| 예산 | 일일 모델 사용 한도 |

프로필 파일의 해시는 중앙의 정책 등록부에 등록됩니다. 파일이 바뀌면 해시가 바뀝니다. 해시가 등록된 값과 다르면 호스트가 정지됩니다.

## 승인이 필요한 동작

에이전트는 초안을 생성하고 중단합니다. 승인 전에는 아무것도 변경되지 않습니다.

| 동작 | 승인에 결합되는 값 | 차단되는 경우 |
| --- | --- | --- |
| 메모 추가 | 요청자, 승인 ID, 파일, 내용 해시, 정책 해시, 만료 시각 | 같은 승인을 재사용한 경우 |
| 임시 읽기 권한 | 요청자, 경로 목록, 정책 해시, 만료 시각 | 차단 목록의 파일을 요청한 경우, 요청과 승인 사이에 심볼릭 링크가 교체된 경우 |
| 코드 변경 | 요청자, 파일별 원본 해시와 결과 해시, 정책 해시, 만료 시각 | 제안 이후 사용자가 파일을 수정한 경우, 비밀 값이 추가된 경우 |

## 기록

| 기록 | 내용 |
| --- | --- |
| 감사 로그 | 모든 판정. 누구에게 무엇이 허용되고 거부됐는지의 기준 기록입니다. |
| 근거 | 응답을 생성하면서 읽은 파일과 실행한 검색 |
| 승인과 영수증 | 같은 쓰기가 두 번 적용되는 것을 방지합니다. |
| 작업 저장소 | 승인 대기 중인 작업이 재시작 후에도 유지됩니다. |

## 구현 중 발견한 문제

- **차단 목록이 불완전했습니다.** 키 파일의 목록이 조회됐습니다. 모델이 파일 내용을 출력하지 않았을 뿐, 정책은 차단하지 않고 있었습니다. 모델의 자제에 의존할 수 없다는 점을 확인했습니다.
- **에이전트가 숨긴 파일을 존재하지 않는다고 응답했습니다.** 숨긴 파일이 있다는 사실과 접근을 요청하는 방법을 안내하도록 수정했습니다.
- **문장 중간에 포함된 비밀 값을 탐지하지 못했습니다.** 검사가 줄 단위로만 비교하고 있었습니다. 단어 단위 비교를 추가했습니다.
- **일반적인 질문이 차단됐습니다.** 로그에 기록된 파일 경로를 비밀 값으로 오인했습니다. 차단 규칙은 실제 파일 전체를 대상으로 시험하고 오탐 수를 확인해야 합니다.

## 장애 시 동작

- **위임 토큰 만료**: 요청을 거부합니다. 감독 프로세스가 중앙 서버에서 새 토큰을 받아야 합니다.
- **승인 후 대상 변경**: 변경을 적용하지 않고 새 제안을 제출합니다.
- **결과에서 비밀 내용 발견**: 결과를 교체하고 요청을 실패로 처리합니다. 응답은 전송되지 않습니다.
